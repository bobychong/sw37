使用说明（小白也能秒懂）

  1. 第一次使用：直接在上面输入BOSS名字和刷新时间（分钟），点“添加BOSS”即可，所有数据自动永久保存在你当前浏览器里，关掉再打开还在！
  2. 打完BOSS了：点BOSS卡片上的“已击杀 - 重新计时”按钮，就会重新开始倒计时。
  3. 发给队友/换设备用：点“导出配置” → 复制一串代码 → 保存或发给队友 → 新设备点“导入配置”选文件 → 秒恢复所有BOSS！
  4. 右上角文本框：随时复制里面的文字直接发群里，队友一看就知道所有BOSS还有多久。
  5. 提醒规则：5分钟黄光 + 弹窗 + 声音 → 3分钟变红 → 1分钟紫光疯狂闪烁 + 尖叫声，绝对不会错过！
  6. 手机电脑通用：保存这个HTML文件扔手机上双击打开一样流畅，完全离线零流量！
